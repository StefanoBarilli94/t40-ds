# Colori

Tutti i colori sono definiti come variabili CSS in `src/index.css`, in formato `oklch`. Il
componente sotto legge le variabili live, quindi riflette sempre il file sorgente.

## Verifica di contrasto (WCAG 2.1 AA)

Calcolato convertendo `oklch` → sRGB lineare → luminanza relativa, soglia 4.5:1 per testo
normale. Tutte le coppie usate per testo rispettano AA.

| Coppia | Contrasto | Esito |
| --- | --- | --- |
| foreground su background | 18.0:1 | ✅ |
| primary-foreground su primary | 10.0:1 | ✅ |
| secondary-foreground su secondary | 16.3:1 | ✅ |
| muted-foreground su background | 4.6:1 | ✅ |
| destructive-foreground su destructive | 4.6:1 | ✅ |
| sidebar-foreground su sidebar | 16.3:1 | ✅ |
| **positive** su background/card | 4.65:1 / 4.85:1 | ✅ |
| **negative** su background/card | 4.59:1 / 4.79:1 | ✅ |
