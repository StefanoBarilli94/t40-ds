# Colori

Tutti i colori sono definiti come variabili CSS in `src/index.css`, in formato `oklch`. I
componenti sotto leggono le variabili live, quindi riflettono sempre il file sorgente.

Il design system serve due brand: **GT40** (default, nessun attributo) e **AST40**
(`data-theme="ast40"`). Le sezioni qui sotto mostrano entrambi i temi fianco a fianco,
non solo quello selezionato nella toolbar in alto — così il confronto è sempre visibile.

{/*
  IMPORTANTE: qui sotto si legge sempre `var(--token)`, mai `var(--color-token)`.
  `--color-token: var(--token)` (l'alias Tailwind da `@theme inline`) è dichiarato
  una sola volta su `:root`: un discendente con `[data-theme="ast40"]` che
  ridefinisce solo `--token` non fa ricalcolare l'alias, che resta "congelato"
  al valore ereditato da `:root` (GT40) — bug reale trovato mostrando i due temi
  fianco a fianco per la prima volta. Il token raw invece cascata correttamente.
*/}

export const swatch = (bg, fg, label) => (
  <div
    key={bg}
    style={{
      background: `var(--${bg})`,
      color: `var(--${fg})`,
      padding: "1rem",
      border: "1px solid var(--border)",
      fontSize: "0.8rem",
    }}
  >
    <div style={{ fontWeight: 600 }}>{label}</div>
    <div style={{ opacity: 0.8 }}>--{bg}</div>
  </div>
);

export const scaleSwatch = (varName, step) => (
  <div
    key={step}
    style={{
      background: `var(--${varName}-${step})`,
      color: step >= 600 ? "white" : "var(--foreground)",
      padding: "0.75rem 0.5rem",
      fontSize: "0.7rem",
      textAlign: "center",
    }}
  >
    {step}
  </div>
);

export const themeBlock = (themeAttr, title) => (
  <div>
    <h4 style={{ marginBottom: "0.5rem" }}>{title}</h4>
    <div
      data-theme={themeAttr}
      style={{
        display: "grid",
        gridTemplateColumns: "repeat(auto-fill, minmax(140px, 1fr))",
        gap: "0.6rem",
      }}
    >
      {[
        ["background", "foreground", "Sfondo pagina"],
        ["card", "card-foreground", "Card"],
        ["primary", "primary-foreground", "Primario"],
        ["secondary", "secondary-foreground", "Secondario"],
        ["muted", "muted-foreground", "Muted"],
        ["accent", "accent-foreground", "Accent"],
        ["destructive", "destructive-foreground", "Destructive"],
        ["sidebar", "sidebar-foreground", "Sidebar"],
        ["sidebar-primary", "sidebar-primary-foreground", "Sidebar primary"],
      ].map(([bg, fg, label]) => swatch(bg, fg, label))}
    </div>
  </div>
);

## Scala tint/shade del brand

Oltre al singolo token semantico `--primary` (usato dai componenti), ogni tema espone
una scala completa `--primary-50` … `--primary-900` per sfondi tenui, grafici e
illustrazioni — stessa tinta (hue/chroma), lightness variabile. Gli step **50-300** sono
pensati come sfondo con `--foreground` sopra (>15:1 verificato); gli step **600-900**
come testo su `--background` (>=4.5:1 verificato, vedi tabella sotto — il 500 non basta,
resta sotto soglia).

## Palette chart

8 colori per tema (`--chart-1` … `--chart-8`), pensati per grafici (Recharts, via
`chart.tsx`) dove servono più serie distinguibili nello stesso grafico. Ogni colore è
verificato ad almeno **3:1** su `--background` (WCAG 1.4.11, contrasto non testuale per
elementi grafici) — non è testo, quindi non serve 4.5:1, ma sotto 3:1 diventa illeggibile
su sfondo chiaro. In AST40 le 8 hue sono scelte evitando un raggio di ~40° attorno a
`--primary` (25°) e `--destructive` (45°), per non confondere una serie del grafico con
un'azione di brand o di pericolo.

## Verifica di contrasto (WCAG 2.1 AA)

Calcolato convertendo `oklch` → sRGB lineare → luminanza relativa, soglia 4.5:1 per testo
normale, 3:1 per elementi grafici non testuali (chart). Tutte le coppie usate per testo
rispettano AA.

| Coppia | Contrasto | Esito |
| --- | --- | --- |
| foreground su background | 18.0:1 | ✅ |
| primary-foreground su primary (GT40) | 10.0:1 | ✅ |
| primary-foreground su primary (AST40) | 5.44:1 | ✅ |
| secondary-foreground su secondary | 16.3:1 | ✅ |
| muted-foreground su background | 4.6:1 | ✅ |
| destructive-foreground su destructive (GT40) | 4.55:1 | ✅ |
| destructive-foreground su destructive (AST40) | 4.61:1 | ✅ |

| **negative** su background/card | 4.59:1 / 4.79:1 | ✅ |
